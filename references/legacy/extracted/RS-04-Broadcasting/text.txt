Broadcasting
• Broadcast (multicast) is group communication 
– One sender, all in a group, deliver and receive 
– No. of members can be static (ﬁxed-size) or dynamic 
– If a node is faulty, group members carry on 
– Since the Internet (and many networks) support only 
unicast, broadcasting takes that into consideration 
• Can be best-eﬀort (messages can be dropped) 
or reliable (with re-transmitting)

async def on_receive(reader, _): 
    """  
    Handle TCP message 
    """ 
    while data := await reader.read(100): 
        ldata = data.decode("utf8").split(",", maxsplit=2) 
        sender, seq, msg = int(ldata[0]), int(ldata[1]), ldata[2].strip() 
        print("Received:", sender, seq, msg) 
buffer[sender, seq] = msg 
        def deliver_message(): 
            for n, x in enumerate(delivered): 
                if (n, x) in buffer: 
                    print(f"Delivering (node={n}, seq={x}):", buffer[n, x]) 
                    del buffer[n, x] 
                    delivered[n] += 1 
                    return True 
        while deliver_message():

Total order broadcast algorithm
• Remember: all nodes receive the messages in the same order 
• Two usual approaches, but not fault-tolerant: 
• Single leader 
– Designate a leader (called sequencer) - "leader election" 
– To broadcast, send it to the leader, the leader will FIFO broadcast to the rest 
– Leader crash is fatal 
• Lamport clock implementation: 
– Attach Lamport timestamp to every message 
– Deliver in the total order of timestamps 
– Issue: how do you know that you have seen all messages with a timestamp 
 ? Need to use FIFO links and wait for messages with a timestamp 
 from every node
