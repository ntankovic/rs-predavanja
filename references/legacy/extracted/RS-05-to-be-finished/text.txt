Retry behavior semantics
• At-most-once: 
– Send a message, no retries, hope for the best... 
• At-least-once: 
– Retry until acknowledged, update can happen 
many times 
• Exactly-once: 
– Retry but be careful not to have any side eﬀects (!) 
– Deduplicate or Idempotency

--- PDF PAGE 27 ---

State Machine Replication (SMR)
• (1) Using FIFO total order broadcast to broadcast 
every update to all replicas 
– Replicas will get the update messages in order 
• (2) Updates are applied in a deterministic order 
on all replicas  
– e.g. according to some predetermined rules 
• (1) + (2) = SMR

State Machine Replication (SMR)
• Close ideas: 
– Distributed ledgers (cryptocurrencies) 
– Smart contracts 
– Serializable transactions 
• Limitations: 
– Has some update latency waiting for broadcast delivery 
– Requires fault-tolerant total order broadcast
